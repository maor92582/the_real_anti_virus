The Real Anti Virus 🛡️
אנטי וירוס לניתוח וזיהוי איומים (Malware Analysis), משלב בדיקות סטטיות ודינמיות בסביבה מבודדת (בפיתוח).

📋 אודות הפרויקט
המערכת נועדה לספק מעטפת הגנה וניתוח קבצים חשודים באמצעות שלוש שכבות הגנה:

בדיקת חתימות (Hash Check): השוואה מול מאגרי hash ידועים.

סריקה סטטית (Yara Scanning): זיהוי דפוסים זדוניים בקוד הקובץ.

ניתוח דינמי (Sandbox): הרצת הקובץ בסביבת Docker מבודדת (מבוססת Linux ו-Wine) וניטור התנהגות בזמן אמת.

תכונות מרכזיות
ניטור דינמי ב-Container: הקמת סביבת Sandbox אוטומטית, הרצת קבצי EXE באמצעות Wine וניטור צריכת משאבים (CPU/RAM) לזיהוי תהליכים עוינים (בפיתוח).

זיהוי מבוסס חתימות: הורדה ועדכון של מאגר חתימות (SHA256) מ-Abuse.ch ובדיקה מהירה של קבצים.

מנוע חוקי Yara: סריקת תיקיות וקבצים מול מאגר חוקי Yara לזיהוי משפחות נוזקה מוכרות.

תמיכה ב-Windows Executables: שימוש ב-Wine ו-Xvfb להרצת קבצי Windows בתוך סביבת ה-Linux של הדוקר (הקוד נעשה על סביבת לינוקס כדי שהקרנל לא יהיה משותף עם המערכת ההפעלה הרגילה ויהיה מוגן יותר וגם כדי שזה יתאים יותר בכל מחשב).
